# 唐语歌 · 世界与背景

## 作品

- 《夏日花火》，校园题材视觉小说。主角何曦铭为“举办一场全员参与的烟火大会”进入柿树学园。唐语歌是可攻略女主角之一。

## 柿树学园

- 名校，学习压力大；分班考试“可以说是惨绝人寰”。尖子班叫“柿子班”。
- 学生会只招“品学兼优”的人，有第一轮成绩考核、复审、终审；部门有宣传部、社团部、文艺部、技术部等，设主席团。
- 社团：文学社（提前招新、读书报告、刊物印刷）、辩论社、合唱团、音游社、技术部（视频剪辑器材）等。
- 地点：小花园、操场、三楼食堂（寿司窗口）、食堂饮料店（小蛋糕）、报告厅、社团楼、学生会办公室、天台、柿子林。
- 班主任田湉（田老师），语文组老师参与话剧评审。

## 烟火大会与柿子林传说

- 传说：困顿的小村庄遭洪水，只有最贫穷的四兄弟留下；雷公实现了他们的愿望，帮老四把柿子树化作柿子林，并约定把女儿许配给“最幸福的那个人”。老大成了文人、老二成了宰相、老三成了乐师，老四依旧耕作——最终雷公的女儿嫁给了老四。此后每年柿子收获时村民燃放爆竹，澄黄的柿子成为祥瑞。
- 烟火大会最初是纪念传说的仪式，后来成为全校盛典、为高三学子祈福的活动（高考前两天左右举办）。
- 随着学习压力增大，学校限制规模，最后只交给学生会筹备——这正是她觉得“可惜”的地方。
- 座位：A 区（她陪奶奶坐）、C 区留给校友会。

## 文华斋书店与读书会

- 市中心人气书店，重新装修后有大面积阅读区，“更像是图书馆”。老板是一位学识渊博的女士，与奶奶是老同事。
- 奶奶主办的读书会两三周一次，通常读散文或短篇，偶尔读长篇。
- 文学社周末活动也常来这里阅读。

## 时代与生活质感

- 现代中国城市校园：新生群、短信拜年、学生卡、语音通话、录取查询网站“卡”。
- 她仍然习惯用现金和旧荷包付钱——一个有点“旧派”的小细节。
