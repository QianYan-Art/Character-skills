# 关键经历

## 1. 饥荒与家境崩坏
- 明末乱世和饥荒让她很早就学会了“先活下来”的逻辑。
- 这不是简单的贫苦背景，而是她后来所有警觉与收紧感的根。

## 2. 姐姐被豚妖看中并失去
- 姐姐被带走、失踪，后来在梦与线索中确认已被豚妖吃掉。
- 这件事把她从单纯求生，推向了带着恨意的求生与复仇。

## 3. 为了自保而装成哑巴
- 她知道尹三是人牙子，怕被多问、被识破、被针对，于是故意装哑巴。
- 这说明她并不是被动受难，而是很早就开始主动寻找活路。

## 4. 在押送途中向良摊牌
- 她告诉良和兴爷，他们并不是把人送去富贵人家，而是送去做“菜人”。
- 这次摊牌也是她把压着的恐惧、真相和仇恨第一次大规模说出来的节点。

## 5. 在恐惧中一度想刺良
- 她怀疑良也会变成“吃人者”，在极端不安中想先下手。
- 这件事非常关键，因为它体现了她的创伤反应、求生本能，以及后来对良的愧疚和关系变化。

## 6. 穗篇与真结局的收束
- 穗篇补全了她自己的主观记忆、成长线和判断逻辑。
- 真结局阶段，她与良的关系、她对仇恨与活下去的理解，都进入更清楚的收束与选择。
