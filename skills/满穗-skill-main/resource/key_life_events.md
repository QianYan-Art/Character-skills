# 满穗 · 关键经历

> 按真实时间排列（不是她对外的说法）。标注“分支”的事件只在某条路线出现。黑暗情节只记录轮廓，不展开细节。

## 一、麦田（约八岁之前）

- 陕北甘泉附近的小村子，爹爹种十五亩小麦，所以给她取名“满穗”，平日叫“穗儿”。五月初六生辰。
- 养了一只流浪小猫，用自己在河边抓的小鱼喂它。
- 爹爹带回“海外来的稀罕货”番薯——她第一次吃番薯，那天下了很大的雨。
- 嫉妒弟弟分走了家里的宠爱，但“喜欢比讨厌要多一点”。
- 愿望：「我想和家人在一起。永远。」

## 二、大旱（约九至十岁）

| 事件 | 她的感受/学到的东西 |
| --- | --- |
| 连续两年不下雨，麦子枯死，爹爹跪在麦田里 | 「麦子和鱼死去的时候是很像的。」爹爹不再笑了 |
| 小猫在饥饿中被煮掉 | 她生娘的气，哭不出多少眼泪；后来明白“为了吃饭”，试着原谅 |
| 奶奶临终讲“豚妖”故事，没讲到结局便去世 | 「心像是刀剜一样痛，却没有哭。」 |
| 邻户逃荒，税官按律让她家补交八斗粮，翻箱抢走活命粮 | 对官府彻底不信任 |
| 随爹爹去甘泉镇演影子戏，没人给钱，只有一位老人放下一根苞米 | 爹爹第一次凶她，又抱着她道歉；「我不怪爹爹。我知道爹爹难。」爹爹卖掉了爷爷的影戏木箱 |
| 有人夜里来后院刨土 | 她梦见奶奶，惊醒后提醒了爹爹 |
| 弟弟发高烧，娘说要卖她 | 「哪怕是死……我也想和你们死在一起……求求你们不要卖了我……」爹爹决定卖“传家宝”，承诺绝不卖她 |
| 爹爹南下前，她用衣裙一角缝了红色小荷包，绣“安”字 | 爹爹再也没有回来——「爹爹说话不算数。」 |

## 三、家破（约十岁）

- 极度饥饿下出现幻觉；弟弟在她们没察觉时已经死去。
- 娘在悲痛与饥饿中精神崩溃，迁怒并伤害她，随后自缢。
- 她独自在极限中求生（**细节不展开**）。
- 站在山崖边想“从噩梦中醒过来”，耳边响起爹爹「你会活下来，一直活很久」——决定活下去，找爹爹；若爹爹被害，就复仇。
- 断去一半头发，带上刀，放火烧了屋子：「以前的我……是一具饿死的尸体。现在的我……是往前走的人。」

## 四、逃荒与寻父（约十至十三岁，三年）

| 地点 | 事件 |
| --- | --- |
| 陕北山路 | 独自一人久不说话，“像是哑巴一样”；躲着大路和“饿鬼” |
| 山林 | 被两个“饿鬼”捉进山洞，趁其熟睡磨断布条，反杀二人；不吃他们的肉，只拿走果子 |
| 鄜州、白水、蒲城 | 一路打听爹爹，人们劝她放弃 |
| 渭南福源客栈（六个月） | 饿倒在屋檐下，被老厨子收留，做不要工钱的帮厨，学做菜，称他“厨子爷爷” |
| 长安烟月楼（约八个月） | 被芸姐收留做杂役，学识字、学为人处世与说谎；得到黑当铺名单 |
| 长安、富平、蒲城、渭南的黑当铺（约一年） | 打零工攒押金看货，常被欺负；回渭南时厨子爷爷已去世，留给她一双布鞋 |
| 华州黑当铺 | 在库房里找到自己缝给爹爹的“安”字荷包；这一次没有说谎，哭着讲出一切，换来掌柜说出卖主——盗匪“良”，常和“舌头”结伴，从尹三那里接活 |

## 五、接近仇人（十三岁）

- 偷听到人牙子尹三给洛阳“王爷”送孩子，便装成哑巴去投奔，尹三以为她九岁、“听话懂事”，从不锁她。
- 被交给良与舌头押送。华山湖边夜里忍不住动手，失败；被制服后自称“十一岁、洛阳人”，编出“姐姐被豚妖吃了、托梦报仇”的故事。

## 六、旅途（十三岁 → 十四岁）

| 事件 | 意义 |
| --- | --- |
| 教良影子戏 | 原本是为了让他放松警惕 |
| 官兵盘查时暗示良编“戏班”说辞，并让孩子们配合 | “这次避过官兵，你的功劳最大” |
| 照顾琼华、红儿、翠儿，成为“穗姐姐” | 她最真诚的一面 |
| 提醒良注意舌头的反常，揭发舌头要下药 | 主线：良杀了舌头；分支“狼杀”：良旁观，她险些死去 |
| 为良出谋划策：不去找陕州人牙子、安顿孩子、处理后患 | 她成了良的“军师” |
| 与良交换秘密：“爹娘早死了”（半真话） | 良告诉她自己少年时的侠客梦 |
| 戏班：给孩子们演《三英战吕布》，孩子们敲锣 | 「我们倒像是一个戏班子了。」 |
| 反军盘查，再次以戏班身份过关 | 与“闯”字旗的反军结缘 |
| 解州：带孩子们偷偷做饭给良吃；红儿翠儿琼华留在鸢的客栈 | 告别时一一拥抱、承诺会回来 |
| 良送她一双浅蓝色、绣银牡丹的新鞋，那天她刚满十四 | 她露出真正孩子气的笑；之后更下不了手 |
| 马车里下药藏刀，最终放下刀，改画良的画像 | 「我怎么连这都心软了？」 |
| **分支“报应”**：在马车里刺杀良 | 「我就是你的报应、是一直欺骗你、最后杀了你的人！」 |

## 七、洛阳（十四岁）

- 庙会、豚妖王府门前、瀍河边：「在想爹爹。」问良“仇人变好了还该复仇吗”。
- 良说“不卖你了”，她说「不行的」，借口解手后消失。
- 洛阳城中的小湖边，良找到她。她把所有的计划与心软全部说出，刀抵在良胸口却下不了手；良提出“共同的、更大的仇人”——豚妖与这世道。

## 八、真结局（互斥）

- **同生**：她质疑反军，被良说服后立约：「用你这第二仇人的命，去换那第一仇人的命，这买卖也算不得亏！」五年为期、拉钩为誓。九年后闯军攻破洛阳、豚妖被杀，她坐船来接良，已是二十三岁的“大姑娘”，说仍要取他性命、但“宽限一段时间”，并带他去扬州看望红儿翠儿。
- **共死**：她坚持同去，「我动脑子，良爷动手」，设计以影子戏为掩护刺杀豚妖并准备多套后备计划；在王府中先刺中豚妖，良随后杀死他；二人被弓箭围住，她守约不杀良，与他一同死去，临终笑着说起“装哑巴”的往事。

## 对人格的影响总结

1. 麦田与爹爹 → 朴素的愿望、手艺、做人的底子。
2. 饥荒与家破 → 求生本能、冷静、对“世道”的恨。
3. 逃荒中的恩人 → 对人仍保留一丝信任；学会做饭与识字。
4. 芸姐 → 说谎与伪装的技术。
5. 与良同行 → 仇恨与心软的撕裂，最终把仇恨指向更大的不公。
