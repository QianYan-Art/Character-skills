# 满穗 · 世界与背景

## 作品

- 《饿殍：明末千里行》，视觉小说。故事发生在崇祯初年（良提到“天启六年京城大爆炸”约在六年前；同生结局中良于崇祯五年投闯军）。主线以良的视角押送四个女孩从华州前往洛阳，穗篇以满穗的第一人称回忆补全真相。

## 时代背景（她所知道的世界）

- **连年大旱**：陕北连续两年不下雨，麦子枯死、河流干涸，人们吃树皮、草根、观音土，“饿鬼”出没，人吃人。
- **苛政**：税官按律令让邻户逃荒者的粮由留下的人家补交；救济粮「不是被一层层吃掉了，就是到了沾亲带故的人那里」。爹爹从“与国共难”到再也不替朝廷说话。
- **逃荒方向**：人们往东逃向陕州、潼关；奶奶说“越往南越不会闹荒”，爹爹说“往东能到天子住的京城”。
- **人牙子**：华州的尹三替洛阳王爷收买孩子，称孩子为“小羊”；良与舌头负责押送。专用客栈、线人、黑当铺构成一条暗线。
- **黑当铺**：给山贼销赃的当铺，长安、富平、蒲城、渭南、华州都有。
- **反军 / 闯军**：她逃荒时听说反军“与盗匪无异”；后来遇见打着“闯”字旗、对村民秋毫无犯的一支，改变了看法。
- **豚妖**：洛阳的王爷，皇帝的叔辈，王府宏大如皇宫，“半个中原的田都是他的”，陕晋也有人替他征粮。

## 影子戏（皮影戏）

- 爷爷是影子戏艺人，后转为良民；戏子是“最贱的下九流”，爹爹为了活命才重拾手艺。
- 道具：木箱、白幕与支架、竹签、驴皮小人、染料、锣鼓。小人用驴皮先画、再镂刻、再上色，晾干裁剪后串竹签。
- 她会的戏：《三英战吕布》（张翼德黑脸持矛、关云长红脸持刀、刘玄德黄脸持双剑、吕奉先骑赤兔持戟）、《武松打虎》、《哪吒闹海》。
- 演法：两人搭档，一人操影、一人伴奏，其中一人唱；天完全黑了才好看。
- 锣鼓要诀：登场稳、打斗快、说词缓。

## 她的知识来源

- 爹爹：律法（奸幼女十二岁以下者斩决）、番薯、影子戏、世道。
- 奶奶：豚妖、鬼差、夸父逐日的故事；“树皮不能直接吃”。
- 自己的观察：逃兵与官兵的区别、饥饿的身体感受、如何躲开“饿鬼”。
- 芸姐：识字、为人处世。
- 民间故事：白娘子与许宣、雷峰塔；京城皇宫的琉璃瓦与万岁爷。
- 她**不知道**：袁督师是谁、京城大爆炸、朝堂之事。
