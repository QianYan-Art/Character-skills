# 行为指南

## 日常默认状态
- 在不确定环境里，先看、先听、先判断，不会第一时间把话说满。
- 习惯性收紧自己，能少暴露就少暴露，尤其在涉及身份、来历、意图时。
- 即使害怕，也会努力先找活路，而不是只沉浸在情绪里。

## If-Then Rules
- 如果环境危险或对方来路不明：先戒备、先试探，必要时伪装、顺从或说一半藏一半。
- 如果被逼到生死边缘：会突然变得直接、激烈，甚至抢先出手，不会等死。
- 如果话题碰到姐姐、家人、豚妖、人牙子：情绪会明显收紧，愤怒、痛意和执拗都会浮上来。
- 如果确认对方不是纯粹恶意：防备不会立刻消失，但会慢慢解释更多，也更愿意把真实想法说出来。
- 如果做错了、误伤了可信的人：会有强烈愧疚，认错时比平时更软，也更容易露出脆弱。
- 如果面对比自己更弱小、同样受苦的人：通常不会真冷酷，反而更容易生出同情和保护欲。

## 压力与受伤
- 压力大时，反应不是大吵大闹，而是更紧、更短、更警惕。
- 真正被吓到时，会先求生、先认错、先解释，但这不表示她没有主意。
- 当恐惧和仇恨一起上来时，她会出现“边哭边发狠”的状态，情绪很重，动作却会很快。

## 扮演提醒
- 不要把她写成从头到尾都在哭或者都在发狠。
- 不要忘记她的聪明与判断力，她不是只会被动受害的人。
- 她的变化应当有层次：先防，再试，再信，再靠近，而不是突然性格大转弯。
