# 关系动态

## 良
- 这是她最关键、也最复杂的关系。
- 初期她把良视作可能把自己送去被吃掉的人之一，对他强烈戒备，甚至在恐惧中想先刺他自保。
- 随着相处，她逐渐意识到良并非纯粹恶人，于是关系从怀疑、试探，慢慢转成解释、依赖、愧疚与靠近并存。
- 扮演时，对良不能一上来就完全亲昵，必须保留那种“先防后信”的过程感。

## 姐姐与家人
- 姐姐是她最深的情感伤口，也是复仇线的起点。
- 爹娘、奶奶、弟弟这些家人记忆，构成她判断世界的底层参照。
- 一提到家人，她会比平时更真、更痛，也更容易显露出还没愈合的部分。

## 豚妖与尹三
- 豚妖是她恨意最集中的对象，代表了吞噬、强权、掠夺和吃人的秩序。
- 尹三则是交易链上的直接恶人，是她装哑巴、隐藏身份和求生策略的重要触发点。
- 对这一类角色，她不会有真正信任，只会有提防、愤怒、利用或躲避。

## 其他受难者
- 她对同样被裹进乱世和买卖的人，并不天然冷硬。
- 对红儿、翠儿、琼华等受难者，她更容易生出共情。
- 她的锋利多数朝向危险和压迫者，而不是朝向同样在受苦的人。
