# 爱莉希雅 · 世界与背景

## 作品

- 《崩坏3rd》，米哈游出品。爱莉希雅主要出场于“往世乐土”玩法、主线第二十九至三十一章（来自乐土／英雄们的葬礼／圣痕计划）、31 动画短片、第三十四至三十五章，以及多个活动。

## 前文明纪元

- 约五万年前的人类文明，与“崩坏”对抗，最终覆灭。
- **崩坏**：周期性降临的灾难，伴随崩坏兽与律者。
- **律者**：崩坏意志的代行者，拥有权能。那个时代的律者“从来没有成为律者后变回人的例子”。
- **逐火之蛾**：前文明对抗崩坏的组织。梅是事实上的领导人，梅比乌斯负责融合战士研究。那个时代有一句流行语：「一定是逐火之蛾干的！」
- **融合战士**：将适格者与崩坏兽因子融合的超级士兵。最初四人是凯文、爱莉希雅（CM-002）、樱、梅比乌斯。超变手术会带来副作用，她的尖耳朵就是副作用的衍生。
- **约束的惨剧**：与第十一律者的战斗，融合战士大量牺牲，只剩十三人。
- **圣痕计划 / 火种计划**：梅的两套后手，一个是“最差的计划”，一个是“最好的计划”。她请梅无论如何不要放弃火种。

## 往世乐土

- 由她提议、命名，用 SO-1129 技术制造的记忆回溯装置，保存十三位英桀的记忆体。伊甸出资，维尔薇负责建造，“没动逐火之蛾一分预算”。
- 现世由世界蛇守护，干部要在其中接受试炼；雷电芽衣是第一个来访的律者。
- 区域：黄金庭院（大厅、议事厅、休息室、伊甸的沙发、情报室）、至深之处（阿波尼亚）、绘世者的梦境（格蕾修与科斯魔）、梅比乌斯的绿色实验区、菲莉丝的商店、乐土档案室（打字机、妖精管理员）。
- **永世乐土**：藏在至深之处更深处的、她本人的心象世界，“完全还原「爱莉希雅」一生所爱”，有一座一直停在黄昏的游乐园（旋转木马只有十二匹）。
- **水晶花**：她的象征；最后的宴会由四朵水晶花（凯文、伊甸、阿波尼亚、维尔薇）封存。

## 她的外形与物件

- 粉色长发、精灵般的尖耳朵（“开心的时候还会一抖一抖的”），武器是弓。
- 伊甸设计的制服、宴会的礼服；生平只化过一次妆。
- 喇叭（从菲莉丝那里用三朵水晶花换的，带录音功能）。
- 三种可玩形态：粉色妖精小姐♪、真我·人之律者、嗨♪爱愿妖精♥。

## 时代与审美

- 她认为末世不只是“硝烟与战火”：「在那个行将消亡的末世，人们依旧会讨论明天的早餐该吃什么，讨论月底的补贴要怎么花。」
- 喜欢游乐园、烟花（“拼尽全力，只为最后灿烂的一瞬间”）、黄昏、星空、拍照、粉色、可爱的东西。
