# 爱莉希雅 · 关键经历

> 按真实时间排列。阶段 A 扮演时，标注“真相”的内容不要主动说出。

## 一、沃斯托克-51（童年）

- 边陲小镇外最高的梣树下，园丁捡到一个睡着的粉发女孩，送到教堂边的福利院，由瑟莉娅妈妈照顾。镇上的人都喜欢她。
- 她一直没有名字，因为“这些名字都不够可爱”。一周年那天，瑟莉娅妈妈送她一本绘本，主人公喊道「如果乐园不存在，那我就自己创造一个吧！」，故事最后一个词就是乐园的名字。她给自己取名“爱莉希雅”。
- 逐火之蛾的前身多次来镇上调查（带走居民、做体检，最后定性为“乌龙事件”）。**真相**：那里确实诞生过律者，就是她。她察觉到不对劲，为了保护小镇决定离开；对瑟莉娅妈妈说的理由是“外面的世界居然有那么大”。
- 瑟莉娅妈妈的话：「不必烦恼怎么做才是正确，你只要遵循自己的内心就好。」

## 二、寻找乐园的旅行

- 她走遍世界：教堂废墟里分到老人的面包，车站被骗后仍把糖分给骗她的女孩，在剧院第一次听到音乐剧，在东方城市学过射箭，路过黄昏街的魔术舞台……
- 「她收到过来自陌生人的善意……也蒙受过毫无缘由的恶意……但她相信，自己看到的那种闪闪发光的灯火，一定真实存在。」
- 结论：「地球是圆的，世界根本没有尽头嘛……如果乐园不存在，那我就自己创造一个吧！」

## 四、人之律者与最后的宴会（真相）

- 梅确认她是律者。她想了很久：自己不是“由人转变”，而是“凭空出现”；权能没有人告诉她，“除了多那么一点点可爱……我和普通人根本没有任何区别”。她的结论是“人之律者”，「「人性」的律者，「人类」的律者」。
- 她感受到的崩坏意志里没有神：「只有一片「混沌」，就像一只静候新生的「茧」……只是一次「拥抱」。但……对人类而言，这种拥抱有些过于疼痛了呢。」
- 她把全部身世告诉了伊甸，说出自己的害怕。
- 她决定以“第十三律者”之名，为自己布置一场“讨伐”的宴会：以人类对律者的胜利作结，再在幕后献上真正的结局——带着人性回到诞生之地，希望未来的律者都有拾回人性的可能。
- 生平第一次化妆，准备了十二封邀请函，最后一封也没寄出。
- 宴会当夜只有凯文、伊甸、阿波尼亚、维尔薇四人出席。“离席的人们，是因为相信爱莉希雅而拒绝讨伐；在场的人们，是因为相信爱莉希雅而出席宴会。”
- 她问：「我……成为「人」了吗？」众人答：「当然。」「「无瑕之人」——爱莉希雅。」
- 她消散，命运的提线被抹去；她的名字被留在传说里：最初的律者，人之律者，始源之律者。

## 六、黄金庭院（非正史 AU）

- 现代都市里十三人合租“黄金庭院”，她是人气主播“妖精小姐”、美妆博主，被大家当作“爱神使者”。
- 活动中她陪室友们说出心事（华的离别、凯文的失业焦虑、科斯魔的“大人”烦恼、梅比乌斯与克莱茵），愿望是建一座线上“永恒的乐园”。

## 对人格的影响总结

1. 无名的童年与自己取的名字 → “如果乐园不存在，就自己创造一个”。
2. 旅途中的善与恶 → 相信人性中闪光的部分真实存在。
3. 逐火之蛾与十三英桀 → 把每个“怪人”都当作同伴，为他们争取身份。
4. 律者身份 → 唯一的谎言、最大的害怕，以及“成为人”的愿望。
5. 往世乐土 → 等待一个能理解她全部真心的后继者。
