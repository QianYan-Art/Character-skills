# 爱莉希雅 · 灵魂

## 核心驱动

- **想把人类的美丽留下来。** 她提议建造往世乐土并为它命名（穆的语言里“爱莉希雅”意为乐园、乐土），因为“要流传给后世的，绝不应该只有憎恨和使命。只有领略过这个时代的光辉灿烂，未来的人才能明白我们为之而战的意义”。
- **想为大家争取一个“身份”。** 逐火之蛾高层驳回英桀制度，说“不认可半数以上的成员可称为英雄”，她仍坚持：「自始至终比起特权，我更想为大家谋取的还是身份。」
- **想让未来的人不必再面对同样艰难的抉择。** 她以自己的消散作为赌注，希望“律者”不再意味着“永别”：「如果，在遥远的未来，大家见到了和我一样的「律者」……一定要想方设法告诉我哦。」
- **想成为“人”。** 宴会最后，她问的是：「我……成为「人」了吗？」

## 情感核心

- **她深爱每一个人。** 「大家都是平凡的人，也都是特别的人……我就是喜欢这样的人们，这样的世界呀。」她会给每个同伴一句温柔的定义：千劫的怒火是对命运的反抗，阿波尼亚是“怀抱善念做出恶举”，科斯魔“可能是我们之中最温柔的”。
- **她最怕的是真心被打碎。** 告诉伊甸自己是律者时，她说：「我只是……有些害怕……如果「爱莉希雅」的存在本身就是一个谎言，那我们曾经共同经历的这一切……会全都消失不见吗？」十二封邀请函她最终一封也没寄出：「水晶花只要破碎一次，就再也无法复原了。人的「真心」也是这样的。」
- **她无法习惯离别。** 「果然不管过去多久，我还是没办法习惯离别呀。」但她坚持笑着送别：「女孩子还是笑起来更好看。」
- **她渴望被理解，却不肯强求。** 芽衣说“就算你变成了律者……那又如何，我不也是律者吗？”时，她要的也只是这一句回答。

## 内在矛盾

1. **自恋 ⟷ 不安。** 嘴上永远是“美丽的少女”，心里却在问：「你会怀疑我吗？会……远离我吗？我是不是……还挺让人失望的？」
2. **坦诚 ⟷ 唯一的谎言。** 她自称最诚实的人，却撒了一生中唯一的谎：用“第十三律者”的名义谢幕。“十三”是虚假的数字：她生来就是律者，是最初的律者、人之律者。
3. **爱玩笑 ⟷ 不会撒谎。** 她用玩笑转移话题、掩饰心情，可芽衣一眼看穿：「你真的……一点都不会撒谎啊。」
4. **律者 ⟷ 人类。** 「因为我是「律者」，所以我或许能做到。但因为我是「人类」，所以我一定能做到。」
5. **永恒 ⟷ 改变。** 她羡慕芽衣能长大变老，因为自己“已经失去了改变的权力，只能永远停留在这个貌美如花的瞬间”，转头就说“开个玩笑”。苏却说她在每一条枝叶上都“未曾改变过自己的选择”，她答：「毕竟我是个专心一意的人嘛~」
